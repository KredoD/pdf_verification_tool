# Проверочные сценарии ВНИИИМТ

Этот документ описывает бизнес-правила первичной проверки пакетов документации. Правила реализованы в `app/artifact_rules.py`, а используются при формировании отчета в `app/verification.py`.

## 1. Общий обязательный эталон

Для любого пакета должен быть проверочный документ: заявление, ЕГРЮЛ или иной master-документ, который сотрудник считает источником корректных реквизитов.

Проверяется:
- ИНН;
- ОГРН;
- организации;
- адресные строки;
- класс риска;
- НКМИ;
- лицензии;
- телефоны и email, если они есть.

## 2. Сценарий УПП

Если в пакете есть документ УПП / уполномоченного представителя, система ожидает бизнес-лицензию или иной разрешительный документ.

Проверяется:
- наличие бизнес-лицензии;
- организация УПП;
- ИНН/ОГРН УПП;
- адрес УПП;
- реквизиты лицензии;
- совпадение данных с заявлением/master-документом.

## 3. Сценарий OEM

Если пакет относится к OEM/контрактному производству, система ожидает договор между отечественным производителем и иностранной площадкой.

Проверяется:
- наличие OEM-договора;
- стороны договора;
- российский производитель;
- иностранная производственная площадка;
- адрес иностранной площадки;
- совпадение адресов с заявлением и/или ЕГРЮЛ;
- лицензии/сертификаты иностранной площадки при наличии.

## 4. Сценарий РФ-производитель

Если производитель российский, система ожидает подтверждение права пользования производственной площадкой.

Допустимые артефакты:
- договор аренды производства;
- ЕГРН;
- документ собственности;
- иной документ права пользования производственным помещением.

Проверяется:
- адрес юрлица;
- адрес производства;
- совпадение адреса производства в заявлении и документе на площадку;
- тип права: аренда / собственность / иное.

## 5. Сверка адресов

Сверка адресов обязательна во всех сценариях. Даже если остальные реквизиты совпали, несовпадение адреса должно попадать в отчет как риск для ручной проверки.

В отчете показывается:
- адрес из проверяемого документа;
- адрес из эталона;
- процент совпадения;
- статус: корректно / расхождение / нужна проверка;
- источник каждого адреса: файл, страница/таблица/параграф/OCR-фрагмент.
