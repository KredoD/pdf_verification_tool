# Checklist для технического директора

## Архитектура

- [ ] Код разделен на независимые слои.
- [ ] Бизнес-правила вынесены отдельно.
- [ ] Нет скрытой зависимости от LLM.
- [ ] Отчет можно формировать без интернета.

## Извлечение данных

- [ ] PDF читаются через текстовый слой и OCR fallback.
- [ ] DOCX читаются как текст, таблицы и изображения.
- [ ] XLSX читаются как таблицы.
- [ ] TXT/CSV читаются напрямую.
- [ ] ИНН/ОГРН/телефоны/email/НКМИ/классы риска/лицензии/адреса извлекаются.

## Проверка соответствия

- [ ] Эталон загружается отдельно.
- [ ] Проверяемые документы сверяются с эталоном.
- [ ] Адреса проверяются отдельно.
- [ ] УПП/OEM/РФ-производитель имеют отдельные правила обязательных артефактов.

## Отчетность

- [ ] HTML-отчет открывается в браузере.
- [ ] DOCX-отчет формируется.
- [ ] JSON-отчет пригоден для интеграций.
- [ ] В отчете есть доказательства по значениям.

## Production gaps

- [ ] Добавить авторизацию.
- [ ] Добавить очередь OCR.
- [ ] Добавить защищенное хранилище.
- [ ] Добавить Dockerfile/docker-compose.
- [ ] Добавить расширенные тесты на реальных пакетах.
