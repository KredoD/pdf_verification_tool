# План тестирования

## Smoke-тест

Команда:

```bash
pytest
```

Проверяет, что:

- извлечение реквизитов работает на демо-файлах;
- отчет формируется;
- бизнес-правила по обязательным артефактам не падают;
- FastAPI импортируется.

## Функциональные тесты на реальных пакетах

Нужно прогнать минимум 4 типа пакетов:

1. УПП + бизнес-лицензия.
2. OEM + ЕГРЮЛ + OEM-договор.
3. РФ-производитель + ЕГРЮЛ + аренда/ЕГРН.
4. Общий комплект с заявлением как master-документом.

## Что проверять в отчете

- Извлечены ли ИНН/ОГРН.
- Появились ли телефоны и email.
- Найдены ли организации.
- Найден ли класс риска.
- Найден ли НКМИ.
- Найдены ли лицензии.
- Найдены ли адресные строки.
- У каждого значения есть источник.
- Адреса сравниваются отдельным блоком.
- В артефактах корректно подсвечены отсутствующие документы.

## Negative cases

- Документ без текста и без OCR.
- Документ без ИНН.
- Пакет УПП без бизнес-лицензии.
- OEM-пакет без договора.
- РФ-производитель без аренды/ЕГРН.
- Расхождение адресов.
- Расхождение ИНН/ОГРН.
