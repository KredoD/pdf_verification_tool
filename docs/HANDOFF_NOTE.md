# Передача проекта техническому директору

## Что передается

Передается ZIP-пакет с исходным кодом, тестами, демо-данными и документацией. Код можно открыть в любой IDE как обычный Python/FastAPI-проект.

## Что надо проверить в первую очередь

1. Запуск приложения через `uvicorn app.main:app --reload`.
2. Прохождение тестов через `pytest`.
3. Извлечение реквизитов из тестовых документов.
4. Наличие доказательств по каждому найденному значению.
5. Бизнес-правила для УПП/OEM/РФ-производителя в `app/artifact_rules.py`.
6. Отчетность: HTML, DOCX, JSON.

## Почему проект разделен на модули

Так проще ревьюить и дорабатывать:

- extractor не знает про бизнес-правила;
- verification не знает про HTML;
- artifact_rules можно менять без OCR и парсеров;
- report_builder можно менять без логики сверки;
- main.py только принимает файлы и запускает пайплайн.

## Что не является production-ready

- Нет авторизации и ролей пользователей.
- Нет постоянного защищенного хранилища.
- Нет очереди задач для тяжелого OCR.
- OCR базовый, для промышленных сканов потребуется preprocessing.
- Нет интеграции с API ЕГРЮЛ/ФНС/внешними справочниками.
