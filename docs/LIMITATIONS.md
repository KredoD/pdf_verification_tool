# Ограничения текущей версии

## OCR

Текущий OCR — базовый. Он подходит для первичного MVP, но для production лучше добавить:

- deskew / выравнивание;
- удаление шума;
- повышение контраста;
- бинаризацию;
- batch-обработку страниц;
- кеш OCR-результатов;
- очередь задач.

## Юридическая интерпретация

Сервис не принимает юридическое решение. Он показывает сотруднику:

- что найдено;
- где найдено;
- совпадает ли с эталоном;
- что отсутствует;
- что требует ручной проверки.

## Адреса

Адреса сравниваются fuzzy-методом. Для production желательно подключить нормализацию адресов через ФИАС/DaData или внутренний справочник.

## Организации

Организации извлекаются эвристиками/паттернами. Для более высокого качества можно подключить NER-модель или отдельный справочник контрагентов.

## Ссылки Яндекс.Диска

Сервис не должен зависеть от внешних публичных ссылок. Для production лучше принимать ZIP/папку файлов через интерфейс или интегрировать Object Storage.
