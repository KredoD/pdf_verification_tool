# Безопасность и конфиденциальность

Документы ВНИИМТ могут содержать персональные данные, коммерческую тайну и медицинскую/регистрационную информацию. Поэтому для production обязательны:

1. Авторизация сотрудников.
2. Разграничение доступа к проектам.
3. HTTPS.
4. Шифрование хранилища.
5. Автоматическое удаление временных файлов.
6. Журнал действий пользователя.
7. Запрет передачи документов во внешние LLM без согласования.
8. Локальный OCR и локальная обработка по умолчанию.
9. Настройка retention policy: сколько хранить файлы и отчеты.

Текущий MVP хранит файлы локально в `output/projects`. Для production это надо заменить на защищенное хранилище и политику удаления.
