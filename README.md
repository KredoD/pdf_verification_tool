# VNIIMT Primary Document Checker

MVP-сервис для первичной проверки пакета документов ВНИИМТ: сотрудник загружает эталонный документ и проверяемые документы, сервис извлекает реквизиты и формирует отчет с доказательствами.

## Что проверяет

Сервис извлекает и сверяет:

- ИНН
- ОГРН
- телефоны
- email
- организации
- классы риска
- НКМИ / код вида медицинского изделия
- лицензии / разрешительные документы
- адресные строки

Главная идея: каждая найденная сущность в отчете должна иметь доказательство — файл, страницу/таблицу/абзац/OCR-картинку и текстовый фрагмент, откуда значение было взято.

## Бизнес-сценарии

1. Общий пакет: обязательно должен быть master-документ — заявление, ЕГРЮЛ или иной проверочный документ.
2. УПП: если есть УПП, ожидается бизнес-лицензия / разрешительный документ.
3. OEM: если есть OEM, ожидается договор между отечественным производителем и иностранной площадкой.
4. РФ-производитель: ожидается договор аренды, ЕГРН или документ о праве собственности/пользования производственной площадкой.
5. Адреса: сверяются отдельно во всех сценариях.

## Как запустить локально

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Открыть в браузере:

```text
http://127.0.0.1:8000
```

## CLI-запуск без браузера

```bash
python scripts/run_local_check.py \
  --project-name "Demo VNIIMT check" \
  --reference sample_data/egrul_reference.txt \
  --documents sample_data/business_license.txt sample_data/oem_contract.txt sample_data/lease_agreement.txt \
  --out output/demo
```

Результаты появятся в папке `output/demo`:

- `report.html` — отчет для сотрудника
- `report.docx` — отчет Word
- `report.json` — машинный отчет для интеграции

## Структура проекта

```text
app/
  main.py              # FastAPI веб-интерфейс и API
  extractors.py        # чтение PDF/DOCX/XLSX/TXT + OCR + извлечение сущностей
  verification.py      # сверка с эталоном
  artifact_rules.py    # бизнес-правила по обязательным артефактам
  report_builder.py    # HTML/DOCX/JSON отчеты
  models.py            # dataclass-модели отчета
  config.py            # настройки
  utils.py             # нормализация, fuzzy helpers, безопасные имена
scripts/
  run_local_check.py   # локальный запуск без веб-интерфейса
tests/
  test_smoke.py        # smoke-test
sample_data/
  *.txt                # демо-документы для проверки логики
output/
  sample/              # пример готового отчета
docs/
  *.md                 # документация для техдиректора
```

## Что важно понимать техдиректору

Это MVP для первичной проверки, а не финальный юридический эксперт. Он помогает сотруднику быстро увидеть расхождения и доказательства. Для production надо усилить OCR, хранение файлов, права доступа, журналирование, очереди задач и безопасность персональных данных.
